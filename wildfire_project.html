Projet principal

Prédiction de la taille finale des feux de forêt

Pipeline complet de données et de machine learning pour détecter tôt les feux de forêt susceptibles de devenir grands ou extrêmes au Canada.

Python Pandas GeoPandas XGBoost Optuna ERA5 FWI NDVI
Objectif Pipeline Features Validation Modèle Résultats

Objectif du projet

L’objectif du projet est d’identifier tôt les feux de forêt susceptibles de devenir grands ou extrêmes. Le problème n’est pas seulement une régression classique : dans un contexte d’aide à la décision, il est particulièrement important de ne pas manquer les feux dangereux.

≥ 1000 ha Seuil gros feu
≥ 10000 ha Seuil feu extrême
2000–2024 Période analysée
4 classes Prédiction ordinale

Pipeline des données

Le projet repose sur un feature store qui combine plusieurs sources de données : feux historiques, météo ERA5, indices FWI, NDVI, topographie, routes, historique spatial des feux et variables statiques issues de SCANFI.

Feature engineering

Une grande partie du projet consiste à transformer des données brutes en variables exploitables pour la modélisation. Les features sont construites sur plusieurs fenêtres temporelles et échelles spatiales.

Validation temporelle

Pour éviter de surestimer les performances, le projet utilise une séparation temporelle. Le modèle est entraîné sur les années passées, calibré sur les années récentes, puis testé sur une année future.

Architecture du modèle

Un premier modèle XGBoost régressif avait tendance à sous-prédire les grands feux. Pour corriger ce problème, le projet utilise une architecture hybride combinant classification binaire, classification ordinale et régression.

Résultats

Le modèle hybride améliore fortement la détection des feux extrêmes, tout en gardant une logique interprétable pour un système d’alerte.
